🎓 Student Grade Calculator

A simple Java-based Student Grade Calculator that calculates a student's total marks, average, percentage, and grade based on marks obtained in multiple subjects.

📌 Project Overview

The Student Grade Calculator is a beginner-friendly Java project designed to demonstrate fundamental programming concepts. The application accepts marks for multiple subjects, performs the required calculations, and displays the student's academic performance clearly.

✨ Features
📝 Accepts marks for multiple subjects
➕ Calculates total marks
📊 Calculates average marks
📈 Calculates percentage
🏆 Assigns a grade based on percentage
📋 Displays the results clearly
⚡ Simple and easy-to-understand Java implementation
